# Avel Tape — ленточный дилей

Ленточное эхо в духе классических Space Echo: петля ленты, головка записи и три воспроизводящие головки, wow и flutter, насыщение ленты и пружинный ревербератор. Часть линейки плагинов Avel. Форматы: VST3 (macOS, Windows) и Audio Unit (macOS).

## Управление

**Шапка.** Поле пресета: стрелки листают пресеты, клик по названию открывает список. **A / B** — два варианта настроек для сравнения; значок цепочки копирует текущий вариант в другой. Шестерёнка — размер окна (60–150 %, окно также тянется за угол). Меню **⋮** — сохранить пресет, сбросить настройки (Init), открыть папку пресетов.

**Транспорт.** **HEAD PATTERN** выбирает, какие головки звучат: I = время задержки, II = 2×, III = 3×, а также I+II, II+III и ALL. Лампы: **TAPE** — на ленту приходит сигнал, **HEADS** — звучат повторы, **MOTOR** — плагин работает. В окне видны повторы при текущих настройках на линейке в долях такта. Скорость вращения катушек зависит от времени задержки.

**Ручки.** Перетаскивание вверх-вниз, колесо мыши, двойной клик возвращает значение по умолчанию. Клик по полю со значением позволяет ввести число, стрелки по краям меняют его по шагам.

| Ручка | Что делает |
|---|---|
| Delay Time | Время головки I, от 20 мс до 2 с. Кнопка с нотой выбирает долю такта, **SYNC** включает синхронизацию с темпом проекта (до 1/1) |
| Feedback | Количество повторов. Выше 100 % петля уходит в самовозбуждение (лампа мигает), насыщение ленты держит его в пределах |
| Mix | Баланс сухого сигнала и эха. Переключатель **DRY / WET** справа убирает сухой сигнал (для посылов и aux) |
| Wow / Flutter | Медленный дрейф и быстрое дрожание скорости ленты |
| Saturation | Насыщение на головке записи, до +18 дБ драйва; каждый повтор насыщается заново |
| Tone | Окраска повторов: DARK, WARM, NEUTRAL, BRIGHT, AIRY. Стрелки переключают названия |
| Spring Reverb | Пружинный ревербератор на входе и повторах |

**Нижняя полоса.**
- **Tape Mode:** CLEAN (чисто), VINTAGE, WORN (глухо, неровно, с пропаданиями).
- **Tape Type:** NORMAL, HIGH (ярче, больше запаса), LOW (темнее, раньше насыщается).
- **Noise:** шипение ленты, от OFF до −30 дБ. Шипение записывается на ленту и повторяется вместе с эхом.
- **Age:** износ ленты: тусклый верх, пропадания, неровная скорость.
- **Flutter Mod:** включает и выключает модуляцию скорости целиком.

Пресеты пользователя хранятся в `Документы/Avel/Avel Tape/Presets` (файлы `.xml`, их можно передавать).

## Установка
- **macOS:** `AvelTape-<версия>-macOS.pkg`: двойной клик → Продолжить → Установить. Если macOS не даёт открыть файл: Системные настройки → Конфиденциальность и безопасность → «Всё равно открыть».
- **Windows:** `AvelTape-<версия>-Windows-Setup.exe`. Если появится «Windows защитила ваш компьютер»: Подробнее → Выполнить в любом случае.

## Сборка
- **macOS:** `bash build_mac.sh` собирает плагин и ставит его себе в `~/Library/Audio/Plug-Ins`. Нужны только Xcode Command Line Tools; CMake и JUCE скачиваются автоматически, первая сборка занимает 5–10 минут. `bash make_installer_mac.sh` собирает установщик `.pkg` в `dist/`.
- **Windows:** собирается на GitHub (`.github/workflows/build.yml`), установщики публикуются на странице Releases. Локально: `cmake -S . -B build` и `cmake --build build --config Release --target AvelTape_VST3`, затем Inno Setup со скриптом `packaging/windows/AvelTape.iss`.
- **Тесты:** `cmake -S . -B build -DAVEL_BUILD_TESTS=ON`, затем запуск `AvelTapeTest` (проверки звука, пресетов и состояния, снимки интерфейса в `shots/`) и `HostTest <путь к .vst3>`.
